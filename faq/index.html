FAQ

Plain answers about Slowlyy.

This page is written to answer the direct questions people ask about Slowlyy: what it is, how it works, what is live now, and what is still being built.

What is Slowlyy?

Slowlyy is a self-custody crypto wallet that adds a delay to outgoing transfers. The idea is simple: money should not leave instantly if there is still time to spot theft, coercion, or a costly mistake.

How is Slowlyy different from a normal crypto wallet?

Most wallets optimize for immediate transfer execution. Slowlyy adds a waiting period before outgoing funds are released, which changes the security model. The goal is to create time for veto, recovery, and intervention.

Is Slowlyy self-custodial?

Yes. Slowlyy is designed as a self-custody wallet. Users keep control of their own keys instead of handing custody to a centralized third party.

Is Slowlyy live now?

The testnet version is live now. It exists to demonstrate the delayed-transfer model clearly. The mainnet product is still in development.

How long is the transfer delay?

The current testnet demonstrates a 30 minute delay. The planned mainnet product is intended to support a configurable delay from 3 to 30 days.

Why would someone want a delayed crypto wallet?

Because many crypto losses happen fast. If a device is compromised or the wrong address is chosen, a delay creates a window to notice the problem and veto before funds are gone permanently.

Which blockchains will Slowlyy support?

The current plan mentions Bitcoin, Solana, Ethereum, BNB, and Cardano, with more chains to be considered later.

Where can I read more about the security model?

The best place to start is the Slowlyy whitepaper, which explains the delayed-transfer idea, the time-verification model, and the current security assumptions in more detail.

What is a signed pending receipt?

A signed pending receipt is a record that a transfer was initiated, entered its waiting period, and was backed by sufficient funds at initiation time. It is not final settlement. The payment remains vetoable during the waiting period and is intended to auto-settle when the delay completes if no veto occurs.
